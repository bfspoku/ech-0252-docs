Example files

This page provides downloadable XML files that serve as fully valid examples of the specified format. These sample files are intended to illustrate correct structure, element usage, and formatting, offering a practical reference for developers during implementation.

The supporting files are first organized by field of application (Federal Elections or Popular Votes). For simplification and clarity, the examples of deliveries for Federal Elections use a fictional canton with a reduced number of municipalities, candidates, and lists. Federal Elections files are then further divided by type of election and electoral system.
