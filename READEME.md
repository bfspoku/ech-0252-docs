# ech-0252-documentation

This repository contains a **static website** built using **HTML, CSS, and vanilla JavaScript**. The site is designed to be lightweight, fast, and easy to host using **GitHub Pages**.

## 🚀 Live Demo

The website is available at:

- <https://bfspoku.github.io/ech-0252-docs/>

## ✨ Features

- Fully static website (no backend required)
- Modular JavaScript structure
- Data-driven content (as JS objects)
- Ready for GitHub Pages deployment

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **GitHub Pages** for hosting

## 📦 Local Development

To run the project locally, you can simply open the `index.html` file in a browser.

> ⚠️ Note:  
> If the project uses `fetch()` to load JSON files, you must serve it via a local HTTP server.

Example by running the following Python code in the folder containing the file `ìndex.html`:

```bash
python -m http.server
# Wait for the following message
# Serving HTTP on 0.0.0.0 port 8000 ...
```

Then, using your browser, go to:

- <http://localhost:8000/>
