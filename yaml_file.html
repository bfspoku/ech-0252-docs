Federal Statistical Office

YAML files

This page provides minimal YAML templates representing the structure of eCH-0252 XML documents as required by the FSO/FCh for Federal Elections and Popular Votes. Each YAML file correspond to one example file and outlines the essential elements and hierarchy needed for a valid implementation and serves as a practical starting point for integration, validation, and maintenance. These templates are intended to help developers quickly understand the core XML structure and ensure compliance with the standard.

The supporting files are first organized by field of application (Federal Elections or Popular Votes). Federal Elections files are then further divided by type of election and electoral system.
